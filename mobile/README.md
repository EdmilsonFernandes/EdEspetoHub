# Ja no Caminho Mobile (Android first)

This folder is an isolated mobile workspace using Capacitor.
It does **not** replace or break the current web production flow.

## Current strategy

- Web remains the source of truth (`frontend` + existing deploy).
- Android app is a wrapper that opens the Hub in WebView:
  - `https://janocaminho.com.br/hub`
- Store pages open in the same app WebView, keeping app-like flow.

## Project structure

- `mobile/capacitor.config.ts`: Capacitor config (app id/name/server URL).
- `mobile/android/`: native Android project generated by Capacitor.

## Prerequisites (local machine)

- Node.js 20+
- Android Studio (SDK + emulator/device)
- Java 17 (recommended for modern Android builds)

## Commands

From `mobile/`:

```bash
npm install
npx cap doctor
npx cap sync android
npx cap open android
```

Generate debug APK:

```bash
cd android
./gradlew assembleDebug
```

Debug APK output:

`mobile/android/app/build/outputs/apk/debug/app-debug.apk`
